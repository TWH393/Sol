# QQ附件与实际输入验收

仅由用户执行。已构建和更新程序，未自动扫码、发消息、读图片或调用模型。

1. 从原快捷方式打开Sol，登录机器人。私聊发送一张清晰图片，会话应出现原消息、图片预览和保存/请求状态；下载打开应与发送原图内容相同。
2. 发送PDF或Word文件，会话应显示真实文件名、大小和下载入口。仅提供文件编号时显示尚未读取正文；要求总结后，如工具提取成功且进入模型请求，会显示提取状态及可展开的实际提取内容。
3. 对图片提问，区分“模型请求已包含图片”和“模型请求使用了识图笔记”；复用笔记时展开核对实际笔记。请求失败应显示未确认读取，不显示已看懂。
4. 图片后紧接一句“看看这个”，同一人消息应保序；其他人的普通文字应继续处理。
5. 下载失败、附件超限或过期时，消息与文件名仍可见并带原因；不出现伪成功预览或猜测附件内容。

会话是接收/发送记录；实际推理仍由原有记忆和历史筛选决定，并不意味着每轮发送完整聊天记录。原件归档不等于模型已读取，成功请求也不等于模型理解正确。

范围是新收到的图片与文件。附件发送、旧QQ聊天导入、转发/引用附件恢复尚未接入本次原生适配。
