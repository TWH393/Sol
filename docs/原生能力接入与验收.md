# GPT与DeepSeek原生能力接入与验收

日期：2026-11-02。本次由用户授权除语音外的原生能力接入。源码接入与账号实际可用分开；没有程序启动、机器人搜索/模型请求或功能验收。

## 三种接入边界

| 能力 | GPT套餐桥 | 官方OpenAI API | DeepSeek Flash官方API |
|---|---|---|---|
| 搜索、网页读取 | 已有web_search透传契约，本轮接入调用 | web_search | 独立Search/Fetch，复用模型Key |
| 图片理解 | 既有图片输入 | 既有图片输入 | Flash图片输入 |
| 图片上传复用 | 未开放Files API，不跨账号上传 | Files API，按哈希复用 | Files API，按哈希复用 |
| 云端代码、图表 | 当前桥未开放 | Code Interpreter | 继续使用Sol本地Docker |
| 原生生图、编辑、透明背景、遮罩 | 当前桥未开放 | Image Generation | 继续使用本地/已配置绘图服务 |
| 文档输入、云端文件检索 | 当前桥未开放 | File Input / File Search | 保留Sol文档提取；DeepSeek Files只处理图片 |
| Shell、Skills、MCP | 当前桥未开放 | 已接对应工具与资源配置 | 可使用Sol本地插件/技能，不伪装服务端工具 |
| 电脑工具 | 当前桥未开放 | 独立公开网页浏览器驱动 | 不是DeepSeek内建工具 |
| 按需加载、组合独立查询 | 既有Sol按类加载 | Tool Search / Programmatic Tool Calling | 既有Sol按类加载与函数调用 |

表中接入表示代码契约，不表示所有型号或账号均有权限。应用中verified保持false。GPT套餐额度不能当作官方API付费额度使用；没有默认切换账号或服务商。

## 界面入口

打开“模型与思考”→“服务商原生能力”。可总开关或逐项允许，设置搜索优先方式。官方API高级工具使用“添加官方OpenAI API模型”入口；按账号填写API Key与实际可用型号，获取型号列表不做对话测试。

DeepSeek无需重复填Key。默认auto优先原生，tavily才使用“功能中心”的Tavily凭据。原生接口缺权限/余额/参数错误直接报告，避免换查询重复撞同一配置错误。

图片服务顺序支持local、remote、native。选native时调用当前任务的官方GPT模型，不暗中用另一个GPT账号；保留已有本地绘图顺序。原生接口失败不自动换到其他绘图后端。支持PNG、透明背景与遮罩；返回透明结果后才视为抠图成功。

MCP配置是[{"id":"标识","url":"https://公开服务/mcp","allowed_tools":["工具名称"],"audience":"admins"}]。默认仅管理员，设all才给普通用户使用；凭据用独立密码框保存到加密库，不写在URL或回显。服务器和工具名单由管理员配置，不允许模型临时指向任意MCP。

云端Skills可填写已审核Skill ID，或把已安装且启用的Sol技能从界面显式上传到当前官方API账号。上传不执行技能测试；不自动把本地技能上传。执行走云端Shell，保留本地技能入口。

电脑操作使用任务专属、无个人登录的浏览器。默认只允许起始网站，或管理员配置的域名；支持截图、点击、滚动、输入、按键、拖动，拦截内网和表单提交等写入请求。它不接管Windows桌面。模型要求额外安全确认时停止，不自动代为确认。

程序化组合仅开放搜索、网页读取、查找文件、读文档、读本人/可访问历史的只读函数；原生JS负责组合，Sol仍校验每次调用的文件与消息权限，不在此入口写记忆、改任务或账号。保留服务端program/caller/fingerprint续传。

## 用量和文件

- 普通对话仍按类加载；官方支持的GPT且已有超过3个函数时才启用原生Tool Search，避免给一句你好追加全工具目录。
- 输入/输出/缓存/思考Token以供应商返回为准，工具次数另记；独立Search/Fetch没有模型Token，但可能按请求收费。工具费用未返回时不声称为0。
- 同一任务的云端Python可复用容器。任务结束/取消/QQ掉线/软件退出只清理自己创建的环境；清理失败记录未确认。
- 云端输入文件经过同一Files.resolve权限校验，临时上传在结束后删除；临时向量库也删除并有过期策略。图片复用上传24小时过期，不永久堆积。
- 云端生成物下载后进入同一文件库，来源引用关联本地原文件；会话页区分“传了文件标识”“交给云端原生工具”“实际提取内容”。
- 云端返回结果先保留到任务工作目录。归档失败停止重生；有远端文件时暂留其环境至服务商过期，不能保证崩溃后仍可恢复。返回数据随既有任务缓存清理规则保留。
- 图片编号复用减少重复上传，不保证减少图片推理Token；已有识图笔记和长期记忆逻辑保留。

## 用户逐项验收（本轮未执行）

1. 先用DeepSeek Flash发“联网查一下今天吉隆坡的天气”。预期不再要求Tavily，任务显示native_search；有实际来源才能回答。不要用这个文本的日期猜天气。
2. 再给一个公开网页，要求读取正文。预期native_fetch记录返回正文，而不是凭网址猜内容。
3. 官方GPT API配置完成后，请“用云端Python计算1到100的平方和并生成图表”。预期结果338350，实际PNG进入文件库；核对native_code_interpreter用量。
4. 使用官方GPT API生成简单图片，检查文件库真实PNG；再尝试原图编辑或透明背景，不把文字说明当图。
5. 给已归档测试PDF指定云端读取或检索，核对页码、数字与本地原件。大文档优先检索，保留阅读笔记。
6. MCP先配置自己的服务器和少量已授权工具；Skills先上传一个已启用的简单技能；分别查看返回结果和配置错误。
7. 在公开网页浏览器执行“打开该网站，点击某公开页面并读取标题”，检查最后截图与网站范围。它不登录账号。
8. 原生程序化工具合并两个独立查询，检查各步骤归属同一任务；原生Tool Search以实际服务端返回调用为准，不预先标为缓存命中。
