# Sol 配色专项检查

范围：按用户明确授权，只检查颜色、文字可读性和深浅色切换，不做QQ、模型、插件执行或文件生成的功能验收。

## 修正

- 主窗口是Window子类，原来的隐式Window样式没有完整应用。现在显式绑定窗口样式及背景/前景，避免深色控件落在白色主背景上。
- 程序创建的说明文字、导航、卡片、提示改用动态资源；不再依赖修改旧画刷，以免画刷被冻结后残留上一个主题颜色。
- 表格单元格、行、选中行、按钮模板文字、下拉条目、输入框、提示、工具提示、滚动条与主题统一。
- 禁用按钮通过中性前景/背景区别，不再整体降低到40%透明度。
- 提高次要文字亮度；浅色橙色文字与橙色按钮底色分开，选中导航使用更深的橙色文字。
- 软件自己的确认/错误弹窗使用共享主题，窗口标题栏也跟随深浅模式。没有修改Windows系统主题或系统文件选择框。
- 浏览器改为两种主题都覆盖组件颜色，清除只为浅色补丁和写死的灰色说明文字。

## 颜色检查结果

| 范围 | 做法 | 结果 |
| --- | --- | --- |
| 原生12个页面 | 隔离配色预览中逐页看暗色，总览、表单、表格另看切回浅色 | 没有发现白底残留或黑字落在暗底的问题 |
| 原生控件 | 查看展开的下拉框、禁用项、表格选中行、确认弹窗；共享样式覆盖提示和滚动条 | 文字与背景可辨认 |
| 原生调色板 | 两种主题共38组语义文字/背景配对 | 全部达到4.5:1，最低4.52:1；详见`build/theme-color-contrast.json` |
| 浏览器12个页面、6个设置标签 | 在两种主题中读取已显示DOM文字与实际背景；共35个页面/标签状态 | 2042次颜色采样，无低于相应文字阈值的项，最低4.52:1 |
| 当前Sol | 以正常退出/重新打开应用的方式更新原生发布文件 | 原始账号、模型配置及用户数据保留；并非功能验收 |

浏览器采样包含跨页面重复的导航，不代表2042个不同控件。当前没有真实任务/文件的页面检查的是其现有空状态；没有为检查颜色生成真实任务或调用模型。

## 隔离预览

`build/ColorReview/Sol.ColorReview.exe`是开发用颜色预览，标题和说明明确标注样例。编译时使用`COLOR_REVIEW`；主程序也保留`--color-review`入口供以后颜色维护。

此模式不启动引擎、不连接QQ/模型、不保存配置、不设置自启动、不执行页面里的业务按钮，也不会把样例写入用户数据。正常Sol启动不展示这些样例。

本轮没有发送QQ消息、进行模型连接测试或执行工具。用户的其余功能验收清单仍未自动通过。
