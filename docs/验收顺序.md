# 首版验收顺序

当前Sol 0.2的具体步骤、测试请求和预期结果见：[Sol验收清单](Sol验收清单.md)。以下为12类能力索引，实际以新版清单为准。

此文件是以后逐项验收的清单，编写清单不代表已经执行。当前不自动发送 QQ 测试消息、不进行模型推理，也不启动 UI 做验收。

## 先看大框架

1. 打开桌面“Sol”，先检查默认暖白橙色界面、深浅切换、Logo、导航、托盘和浏览器入口。若旧预览再次运行，先退出旧版。高级编辑及仪表盘自定义布局暂用浏览器完整页。
2. 先核对安装状态，再配置主模型、管理员和指定机器人 QQ；新软件没有旧账号密钥或旧记忆。
3. 配置需要由本人登录的账号后，再开始下面 12 项。先检查一项，修正后再进入下一项。

## 12 项功能

| 顺序 | 功能 | 要确认的结果 |
| --- | --- | --- |
| 1 | 自然聊天 | 语气有主见、不会随便道歉；普通闲聊简短；连续补充合并；最多10个气泡；不主动附链接 |
| 2 | 群聊接话 | 引用决定讨论对象；明确区分发言人；不@也可记录和适度参与；免打扰和单群设置生效 |
| 3 | 记忆与人格 | 公共优惠信息可跨用户复用；别人私聊不泄漏；只能更改自己提供的记忆；仅核心启动复盘，曲线和版本恢复真实 |
| 4 | 模型与强度 | 在同一界面切换模型；正在执行的任务保留原模型；固定/自动强度只发已声明支持的值；不会自动更换主模型 |
| 5 | 复用与省量 | 同样可共享的工作合并；已有图片笔记、视频索引和文件优先复用；明确重新生成时绕过旧生成结果 |
| 6 | 图片 | 本地/远程实际来源能查看；抠图透明；擦除有选区；引用和转发图片确实取得像素；成品不追加模型看图 |
| 7 | 文档与翻译 | 默认大纲确认；直接做可跳过；Word/PPT/PDF可打开和修改；PDF扫描件能按页读；阅读笔记可回查来源 |
| 8 | Python与学习 | 同任务变量保留，不同任务隔离；计算结果和图表直接交付；复杂题按需复核；任务结束后释放环境 |
| 9 | 视频 | 字幕或本地转写来源明确，抽帧范围不夸大；后续问题能读已有索引；下载失败说明具体平台/步骤 |
| 10 | 任务与提醒 | 耗时任务忙时仍能聊天；按创建者授权协作；能取消；重启/QQ断联后全部中断，不恢复旧提醒 |
| 11 | 用量与权限 | 个人和公共额度分开；不把未知当0；重置仅影响软件限额；管理员权限、使用范围和自主权限有效 |
| 12 | 插件与技能 | 安装不等于完整兼容；依赖升级不自动通过；配置、停用、更新、卸载、恢复可用；管理员QQ安装命令有效 |

## 安装与运行记录

- `build/install*.log`：本次依赖准备的实际输出。
- `state/install-progress.json`：资源准备是否真正完成。
- `build/source-manifest.json`：静态编译的源码指纹；不代表功能检查。
- `开发接续.md`：完成和待处理事项，继续开发前先读。
- `CHANGELOG.md`：本版改动。

## 已知边界

- 当前是开发预览版，没有上线的新版自动发布服务器；已有插件更新由管理员手动触发。
- 第三方插件的消息处理与注册工具为分级接入，不能承诺任意插件完整兼容。接管核心、另起后台模型循环等插件保持待适配。
- 第三方 SDK 的受支持模型入口纳入统一网关；绕过该入口的插件需要适配，不能把这类调用冒充已经完整统计。
- 源码包不含运行凭据、模型权重和用户数据。移到另一台电脑需要重新准备依赖和账号授权。
- 新软件从一个机器人开始；不要把“存了bot ID”当成多账号功能已经完成。
- 供应商套餐百分比无法由Token精确反推；未返回用量时保留未知状态。
- 视频平台、图片服务和各模型接口的实际可用性仍需相应账号环境下验收。
