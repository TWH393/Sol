# 模型思考调节与请求参数

本轮由reasoning.py共享能力声明、配置验证及请求编码；models-ui.js只显示原生值。模型目录明确声明优先，已核实型号使用文档支持范围，未知型号默认不填猜测范围，可由管理员编辑声明。未调用模型测试。

- GPT Responses/套餐桥使用reasoning.effort；兼容Chat Completions使用reasoning_effort。非默认设置明确走共享HTTP网关，避免SDK适配层忽略参数。
- Gemini原生generateContent使用generationConfig.thinkingConfig.thinkingLevel；若明确声明数值范围则使用thinkingBudget。Gemini不再先走OpenAI参数的SDK分支。
- DeepSeek按自身thinking开关及reasoning_effort传递，不把medium伪装成另一原生档位。
- default只表示不指定，由服务商采用默认值；保存值独立属于各模型，切换模型不共用全局强度。
- 记住密钥沿现有加密凭据库处理。当前模型自身密钥仍保留；勾选复用时另外按接口类型+规范API地址索引，给同服务的新型号使用。界面只返回是否保存，不返回原密钥。

2026-11-01核对的主要官方来源：

- OpenAI模型与范围：https://developers.openai.com/api/docs/guides/latest-model
- OpenAI Luna：https://developers.openai.com/api/docs/models/gpt-6-luna
- Google Gemini 3.1 Flash-Lite/Pro范围：https://ai.google.dev/gemini-api/docs/gemini-3
- Google Thinking配置：https://ai.google.dev/gemini-api/docs/thinking
- DeepSeek：https://api-docs.deepseek.com/guides/thinking_mode/

这里只确认代码构建，实际请求是否被账号/具体型号接受仍由用户验收；不把滑杆位置作为Token或费用保证。
