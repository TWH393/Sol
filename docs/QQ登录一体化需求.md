# QQ登录一体化：待实现需求

状态：2026-11-01用户已要求开始修改，已实现Sol原生与网页登录面板；尚未进行真实QQ登录验收。

## 用户期望

LLBot的QQ接入和登录能力也包含在Sol内。用户希望在Sol上直接登录QQ，不需要自己管理独立的LLBot后台或手工串接组件。

目标体验：打开Sol的QQ接入页面，确认指定的机器人账号，在软件内完成登录/扫码，并查看连接状态。把LLBot客户端Token等接入细节的人工配置负担尽量交给软件处理。

## 本轮实现

- 原生设置页直接打开Sol的QQ登录窗口，网页使用同样风格的登录对话框，不再嵌入整个LLBot后台。
- Sol统一调用自己管理的LLBot 8.3.2登录接口，显示二维码、有效期、指定账号、实际账号与机器人连接状态；过期后手动刷新。
- 首次LLBot客户端授权在Sol内填写一次，保存在现有凭据库。LLBot要求的外部客户端授权仍然存在，不能伪称免授权；本地WebUI密码由Sol生成并管理。
- 启动/停止仍只操作本应用的Docker compose项目；组件准备、Docker/WSL失败和二维码失败显示具体环节。
- 登录面板关闭停止轮询，打开时最多轮询五分钟，不后台反复登录。账号不符显示错误，OneBot原有账号校验继续拒绝错误账号接入。
- 此次未启动QQ或真实扫码，没有迁移旧生产机器人的会话。

实现所依据的官方固定版本源码：[登录接口](https://github.com/LLOneBot/LuckyLilliaBot/blob/v8.3.2/src/webui/BE/routes/login.ts)、[WebUI鉴权](https://github.com/LLOneBot/LuckyLilliaBot/blob/v8.3.2/src/webui/BE/auth.ts)、[本地密码文件](https://github.com/LLOneBot/LuckyLilliaBot/blob/v8.3.2/src/main/config/index.ts)。
