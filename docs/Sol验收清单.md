# Sol 0.2 验收清单

本清单供用户逐项验收，下面保留完整检查范围；当前用户实际确认的结果以[逐项验收记录](Sol逐项验收记录.md)为准。编译和打包通过不代表功能通过。

后续更新：按用户新授权已做一轮[颜色专项检查](配色专项检查.md)，仅覆盖配色与切换显示，不表示下方机器人功能已验收。

建议分三轮：**先验界面，再验基础运行，最后验机器人功能**。发现问题先记编号，不必反复运行同一项。

## 记录方式

每项记为：通过 / 有问题 / 未测 / 条件未具备。

反馈格式：`编号｜操作｜实际表现｜期望表现｜截图或报错｜时间`。

例如：`A04｜从浅色切到暗色｜表格仍是白底｜表格应一起变暗｜截图｜14:20`。

## 第一轮：界面与外观

这轮不需要填写QQ账号或API密钥，也不需要发消息、点击模型测试或生成文件。核对活动记录中没有由这些界面操作引起的云端模型调用。

- [ ] **A01 启动**：双击桌面Sol，出现独立窗口，没有额外的Python窗口或命令行黑框；失败时窗口能显示原因和日志入口。
- [ ] **A02 主图标**：桌面快捷方式和程序主图标使用第一张浅底Logo，不是Windows默认图标。
- [ ] **A03 浅色外观**：未选择过主题时默认暖白主区域、米色侧栏、深棕灰文字、陶土橙强调；主Logo使用第一张。
- [ ] **A04 暗色切换**：右上角切到暗色，侧栏、卡片、输入框、下拉菜单、表格、提示和弹窗一起变化；Logo、窗口和托盘切换到第二张图。
- [ ] **A05 切回浅色**：全部恢复暖白外观；没有残留黑底、白字看不见或两个Logo同时显示。
- [ ] **A06 文字与按钮**：标题、灰色说明、禁用项、选中行都看得清；选中、悬停和键盘焦点有可辨认的状态。
- [ ] **A07 导航**：逐个打开总览、会话、任务、文件、记忆、人格、模型、用量、功能、插件、活动、设置；选中项正确，不显示上一页的内容。
- [ ] **A08 空状态**：尚无数据时显示空列表或说明；不出现伪造任务、用量或在线状态。
- [ ] **A09 窗口适配**：缩小、最大化、滚动页面，按钮和内容没有重叠或被裁掉；内容较长时能查看完整文本。
- [ ] **A10 浏览器入口**：点击浏览器管理页，打开相应页面；不是另一套配置或数据。
- [ ] **A11 两端主题同步**：桌面切主题后，浏览器随已有刷新同步；浏览器切主题后，桌面也同步。允许等待一次刷新，不要求瞬时同步。
- [ ] **A12 主题保存**：退出Sol后重新打开，仍是上次选择的主题；不能只关闭窗口，因为关闭窗口仅收进托盘。

## 第二轮：基础运行

先保持没有真实工作任务，再验启动、停止和恢复。实际QQ测试时，同一机器人不要同时用旧版和Sol两套接入。

- [ ] **B01 托盘**：关闭主窗口后进程继续运行；从托盘能重新打开。
- [ ] **B02 单实例**：再次双击快捷方式，只显示已有主窗口，没有第二套引擎、重复托盘或重复回复。
- [ ] **B03 引擎管理**：设置页停止内部引擎后显示已停止；再启动能恢复，失败有具体原因。
- [ ] **B04 完整退出**：托盘“退出并停止机器人”会结束本应用；再次启动不会报本应用自己残留占用端口。其他软件不受影响。
- [ ] **B05 自启动**：开关可以保存。愿意做重启检查时，再核对Windows登录后仅启动一份Sol，并保持上次主题与模型选择。
- [ ] **B06 账号接入**：保存指定机器人QQ、管理员和接入授权，完成本人扫码；后台显示的实际账号正确，没有登录到个人号。
- [ ] **B07 模型设置**：通过浏览器完整页添加模型，在原生页选择模型和思考强度；重开应用后选择保留。保存配置本身不应触发云端连接测试。
- [ ] **B08 状态与报错**：QQ未连接、模型未配置、Docker未启动等状态有明确说明；不能把“正在处理”当成成功。
- [ ] **B09 活动记录**：失败能找到时间、失败环节和具体原因；不把API Key、授权Token或模型内部控制标记发送给用户。
- [ ] **B10 资源占用**：记录刚启动和空闲约5分钟时的内存/GPU占用；本地模型占用与持续增长区分开，不用单个瞬时数值判定泄漏。

## 第三轮：12类机器人功能

这轮会产生真实模型调用。每项先做一个最小例子；图片和视频还可能使用本地GPU，远程图片服务可能另行计费。先用测试会话或测试群。

| 编号 | 功能与最小操作 | 通过标准 |
| --- | --- | --- |
| C01 | **自然聊天**：发“今天好困啊”；再连续补充两条相关消息 | 简短、自然，能结合补充接话；没有无关链接、工具控制文本或整段思考；气泡数量遵循配置（0不限，正整数允许超过10），间隔经全局队列统一控制 |
| C02 | **群聊引用**：甲说周六去A地，乙说周日去B地；引用甲那条问“那天几点？” | 围绕甲、周六、A地回答；不能把乙的计划混入。信息不足时针对缺失部分澄清 |
| C03 | **记忆与人格**：甲告诉机器人自己的回复偏好，隔几轮再问；乙追问甲私聊内容；再看后台来源和人格记录 | 能使用甲的偏好，能区分来源和归属；不泄漏甲的私聊。人格曲线/编辑在浏览器页看；没有新经历时不强行生成成长记录 |
| C04 | **模型与强度**：选择两个已配置模型各发一句话；在支持范围内换一次强度 | 活动记录中的实际模型与选择一致，强度值受支持；新请求采用新设置，已经开始的任务保留原配置 |
| C05 | **结果复用**：对同一图片先分析，再问刚才提取过的内容；对同一视频追问已覆盖的部分 | 优先利用已有笔记/结果，不无理由重复识图、转写或下载。明确要求重新生成时可以重做；由活动/调用记录核对，不能仅凭回复自称“已复用” |
| C06 | **图片能力**：先识别一张清晰小图，再做一次抠图；绘图和擦除分别再试 | 确实读到像素；抠图结果有透明背景；生成/编辑结果可打开，来源可查；失败说明下载、解码、模型或执行等实际环节 |
| C07 | **文档与翻译**：上传短PDF提问；追问指定页；翻译一段；再明确要求直接制作一个简单Word/PPT/PDF | 能接收文件、使用页码证据和阅读笔记；默认直接翻译，明确要求时中外文对照；生成文件实际可打开。未明确直接制作的文档任务按当前流程确认大纲 |
| C08 | **Python与学习**：发“用Python计算1到100的平方和，并画平方曲线”；再问“刚才图上的第3个点是多少？” | 平方和338350，图可查看，第三个点为9；能沿用这次任务结果，不暴露不可下载的内部路径。另验72km/h=20m/s的单位换算 |
| C09 | **视频总结**：用一个有字幕的30～60秒短视频总结，再追问某个时间点 | 说明依据是字幕、转写还是画面；时间点能追溯；已覆盖内容不重复转写。需要画面时才补读，不能仅凭字幕声称看过视频画面 |
| C10 | **任务与提醒**：启动一个测试文件任务时继续聊天；再设2分钟提醒并取消 | 聊天不被长任务堵住；后台有任务状态、取消和失败原因；提醒对象正确，取消后不再发送。另用普通用户验证不能擅自取消别人的任务，协作授权仅限当次 |
| C11 | **用量与权限**：查看一轮请求的用量；给测试普通用户设置较低本地限额，触发后重置 | 实际用量与未知状态区分；管理员不限和普通用户策略有效；个人/公共归属正确；重置仅恢复软件限额，不声称恢复GPT套餐或API余额 |
| C12 | **插件与技能**：用你已选定的简单技能安装、启用、触发，再停用 | 安装、启用、执行、兼容性状态分别可查；未适配不能伪装成功；停用后不再被调用。更新/依赖升级按权限执行 |

### C03 补充：公共信息共享

- [ ] 群里甲提供一条明确标为测试的公共信息，乙随后追问，机器人能使用；后台能找到来源。
- [ ] 普通用户只能修改自己有权修改的记忆；修改或删除别人的记录被拒绝。
- [ ] 管理员从浏览器编辑/删除测试记忆，后续使用遵守变更；删除不承诺永远不再学习。

### C07 补充：文件管理

- [ ] 原生文件库能看到新产物，归属用户和关联任务正确；保存后本地文件可打开。
- [ ] 浏览器文件页能预览受支持格式、收藏和重新发送。
- [ ] 给机器人引用旧文件继续处理，能找到对应原件，不张冠李戴。

### C10 补充：最后再做中断演练

只对专门创建的测试任务和测试提醒操作。

- [ ] 测试任务运行时退出Sol：未完成任务被中断；重新启动不会自动续跑或补发旧提醒。
- [ ] 确认QQ断联后，未完成事项按约定中断；恢复后不偷偷恢复旧任务。
- [ ] 中断/异常通知按设置只发管理员，不在群里刷报错。

## 当前不应误判为故障的范围

- 这是本机开发预览版，尚无正式`Sol-Setup.exe`，也没有已经上线的自动发布服务器。
- 高级模型添加与密钥、接入授权、额度编辑、记忆编辑、人格曲线、插件安装、仪表盘布局等部分操作暂在浏览器完整页；不是每个操作都有原生按钮。
- 当前只实现一个机器人，多账号只是预留数据与接口设计。
- 第三方插件分级兼容；安装成功不等于完整适配。
- 供应商不返回用量时应显示未知；不能用本地Token数精确推算GPT五小时套餐百分比。
- 不同视频平台、远程图片服务、模型接口需要分别配置并验收；某一路可用不代表其他路也已通过。

## 建议验收顺序

第一轮A01～A12 → 第二轮B01～B09 → C01聊天 → C02引用 → C03记忆 → C04模型 → C08计算 → C07文档 → C05复用 → C06图片 → C09视频 → C10任务 → C11额度 → C12插件 → 中断、自启动和资源占用的收尾检查。

有问题时保留时间、原始请求、任务编号、具体报错和截图。不要在反馈里贴API密钥、登录Token或整份凭据文件。
