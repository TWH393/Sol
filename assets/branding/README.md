# Sol 品牌资源

用户提供的两张 JPG 是正式 Logo 原稿；原图完整保留，不裁剪、不重绘、不更换背景。

- `sol-main.jpg`：第一张，浅底主 Logo。
- `sol-dark.jpg`：第二张，暗色模式 Logo。
- 同名 `.ico`：从对应原图编码，包含 16、24、32、48、64、128、256 像素的 Windows 图标。

主图用于 `Sol.exe` 的应用图标和桌面快捷方式。默认浅色界面的侧栏、窗口和托盘使用主图；切换暗色时使用暗色图。浏览器页签随应用选择切换。原生通过 `SolLogoLight` / `SolLogoDark` 资源保存两份原稿，不能互相覆盖。

使用 `scripts/prepare_branding.py` 重新生成 ICO；脚本只做格式与尺寸转换，不修改 JPG。发布目录、内置引擎和源码包均包含这些资源。
