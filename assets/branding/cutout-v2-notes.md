# Sol logo 精确裁边版 v2

- 按用户要求两张分开处理，分别使用此前认可的浅色原图和暗色原图，不使用生成式编辑后变脏的版本。
- 方法：本地像素裁切；从图像外沿查找边框外的连通背景，将其 alpha 置零，再裁到边框范围。框内像素直接复制原图，没有重绘或重新配色。
- 两张输出都是 1136 × 1136 PNG，四个角 alpha=0，内部中心 alpha=255。
- 浅色：`sol-light-cutout-v2.png`；暗色：`sol-dark-cutout-v2.png`。
- 原稿与 v1 均保留，不覆盖；当前未替换软件的应用或托盘图标。
- `prepare-logo-cutouts.ps1` 是本机处理记录，输入指向本次会话的已认可原稿。
